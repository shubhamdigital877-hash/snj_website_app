# SNJ website — header foundation

Next.js / React / TypeScript frontend. The agreed backend is **plain PHP + MySQL**, with Flutter for the mobile app. No Laravel or booking backend has been added.

Run `npm install`, then `npm run dev`. Open http://127.0.0.1:3000. Validate with `npm run build` and `npm run typecheck`.

Includes responsive header, property panels, mobile navigation, keyboard dismissal, native booking preview dialog and an editorial background to preview the header in context. The supplied original SNJ logo is served from public/brand/snj-logo.jpeg, framed with CSS without modifying the original image. Typography uses locally hosted Plus Jakarta Sans. The header includes name/city property search. No stock photography represents actual properties.

Only three verified Google Maps links are used; Pearls Garden location is pending. Booking explicitly says coming soon. Actual reservations, contact numbers, event enquiries and additional pages await implementation. Preview metadata disables indexing until the website is ready for launch.
